## Conclusiones de diseño: ##

|              |                                                                                                                                                                                                                                          |
|:-------------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| Conclusion 1 | El dispositivo objetivo tiene una pantalla alargada para utilizar todos los bordes, por lo que en el desarrollo hay que tenerlo en cuenta para dejar margenes arriba y abajo                                                             |
| Conclusion 2 | Disponemos de muchos sensores por lo que lo ideal es aunque no se utilicen todos, aprovechar los posibles (huella para privacidad, giroscopio y acelerómetro para gestos con el dispositivo o luz ambiental para sugerir un modo oscuro) |
| Conclusion 3 | El dispositivo tiene Android reciente y hardware de sobra para hacer cualquier cosa, por lo que no podemos tomarlo como uno generico, tendremos que unitilizar AVDs o incluso otro para comprobar rendimiento real.                      |
